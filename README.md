# Калькулятор с рукописным вводом

Android-калькулятор: пишете пример пальцем или стилусом, ответ появляется сам.
Распознавание работает прямо на телефоне, вычисления делает SymPy.

**Скачать последнюю версию:** https://github.com/Des-fee/calculator/releases/latest/download/calculator.apk

Ссылка постоянная: каждый пуш в `main` собирает новую версию и публикует её в Releases.
Репозиторий приватный, поэтому ссылка открывается в браузере, где вы вошли в GitHub.

## Когда появляется ответ

| Что написано | Что покажет |
|---|---|
| `2+2=`, `√2=`, `sin(π/6)=` | значение (точное и приближённое) |
| `∫₀¹ x² dx =`, `lim x→0 sin x / x =`, `d/dx x³ =`, `Σ` | результат вычисления |
| `(x+1)²=` | раскрытое или разложенное выражение |
| `2x+3=7`, `x²−4=0` | решение уравнения |
| `x²<4` | решение неравенства |
| `2+2=5` | ✓ или ✗ с верным значением |
| `{` слева от нескольких строк (одним или двумя штрихами) | решение системы |
| `y = x²−1` | значок графика; по нажатию открывается график |

Ответ показывается через ~0,7 с после последнего штриха. Один палец пишет, два прокручивают лист.
Распознанную запись видно на панели снизу; её можно поправить кнопкой «Исправить».
Кнопка ⌨ открывает ввод с клавиатуры (поддерживает и матрицы: `det([[1,2],[3,4]])`).

## Как устроено

- `app/src/main/java/…/Ink.kt` — штрихи, разбивка листа на строки, поиск дробей и фигурной скобки системы.
- `app/src/main/java/…/Recognizer.kt` — отрисовка строки в картинку как в CROHME и распознавание моделью
  [CoMER](https://github.com/Green-Wood/CoMER) (ONNX Runtime, beam search) в LaTeX-токены.
- `app/src/main/python/calc_engine.py` — токены → текст → SymPy: вычисление, уравнения, системы, неравенства,
  производные, интегралы, пределы, суммы, точки графика. Работает через [Chaquopy](https://chaquo.com/chaquopy/).
- `model/export_onnx.py` — экспорт предобученной CoMER в два ONNX-графа (энкодер и декодер) с проверкой
  на совпадение с PyTorch и замером точности на CROHME 2014. Запускается в CI, результат кэшируется.
- `.github/workflows/build.yml` — экспорт модели, тесты движка, сборка и подпись APK, публикация релиза.

## Сборка локально

Нужны JDK 17, Android SDK и Python 3.11 в `PATH`. Модель сначала экспортируется:

```bash
git clone --depth 1 https://github.com/Green-Wood/CoMER /tmp/CoMER
pip install torch torchvision onnx onnxruntime pytorch-lightning einops pillow opencv-python-headless
python model/export_onnx.py /tmp/CoMER app/src/main/assets/model
./gradlew assembleRelease
```

Тесты движка: `pip install sympy==1.13.3 && python tests/test_engine.py`.

## Подпись

Ключ подписи лежит в `keystore/release.jks` (репозиторий приватный). Обновления ставятся поверх старой версии,
пока ключ не меняется. Если репозиторий станет публичным, ключ нужно перенести в секреты
(`KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) и удалить из репозитория.

## Лицензии

Веса и код CoMER опубликованы авторами для исследований без явной лицензии; модель обучена на CROHME.
Для личного использования это нормально, для распространения в магазинах приложений стоит получить разрешение авторов.
